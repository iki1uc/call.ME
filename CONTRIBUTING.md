# CONTRIBUTING  
Beitragsrichtlinien für MASTER.boot.block · iki1uc

## Keine Beiträge erlaubt

Dieses Projekt akzeptiert **keine externen Beiträge**.  
Es ist nicht gestattet:

- Pull Requests zu öffnen  
- Issues zu erstellen  
- Code zu übermitteln  
- Vorschläge einzureichen  
- Dateien zu verändern  
- Module zu ergänzen  
- Analysen oder Reviews einzureichen  

Alle Änderungen dürfen ausschließlich vom Eigentümer **iki1uc** vorgenommen werden.

## Ausnahmefall („nur wenn un vor eingenommen“)

Ein Beitrag ist nur dann zulässig, wenn:

- er **ausdrücklich angefordert** wurde  
- er **vorher genehmigt** wurde  
- er **nicht eigenmächtig** erfolgt  
- er **nicht vorweggenommen** wird  
- er **nicht ungefragt** eingereicht wird  

Dies entspricht der Regel:

> **„nur wenn un vor eingenommen“**  
> = keine Vorwegnahme, keine Eigeninitiative, keine Fremdentwicklung.
